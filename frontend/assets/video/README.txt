Nav bar background video
=========================

Put your video file here and name it:

  nav-bg.mp4      <- the video shown behind the top navbar

Optional (recommended):
  nav-bg-poster.jpg   <- a still image shown while the video loads / on
                          browsers that block autoplay

To change the video later, just replace nav-bg.mp4 (and the poster image)
with a new file of the SAME name — no code changes needed.

Tips:
- Keep it short (5-15s), looped, and muted-friendly (no important audio,
  since it plays muted).
- Compress it (H.264 mp4, under ~3-5MB) so the site stays fast.
- Landscape / widescreen footage works best since the bar is short and wide.
